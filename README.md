# ТЗ-14/2026 · Фотостудия «Кадр 35»

Сайт фотостудии с бронированием залов по часам, расчётом стоимости, веб-аналитикой GA4, UTM-разметкой, приёмом заявок в Google Таблицу и автоответами в Instagram. Практическая работа по дисциплине ОП.03 «Информационные технологии».

## Структура

```
index.html halls.html equipment.html photographers.html ideas.html contacts.html thanks.html privacy.html 404.html
css/style.css            стили (фирменные цвета и шрифты — раздел 2 ТЗ)
js/analytics.js          все события GA4 (gtag('event', …)) — раздел 4
js/form.js               UTM в sessionStorage, проверка и отправка формы брони — раздел 6.3
js/booking.js            выбор зала, даты, времени и часов, расчёт итога — раздел 3.3
js/main.js               меню, галерея, калькулятор, фильтр фотографов, промокод
img/                     фото (WebP ≤ 300 КБ) и картинки Open Graph 1200 × 630
files/                   схемы залов в PDF
apps-script/Code.gs      приёмник заявок (doPost) и настройка таблицы — раздел 6.2
docs/                    журнал запросов, события, реестр UTM, источники фото, записка
screens/                 снимки проверок
```

## Как открыть локально

Сайт — обычные HTML, CSS и JavaScript без сборки. Можно открыть `index.html` в браузере или запустить простой сервер:

```
python -m http.server 8000
```

Сайт публикуется на Vercel автоматически после каждого `git push` в ветку `main`.
